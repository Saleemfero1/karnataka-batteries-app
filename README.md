# Karnataka Battery — QR Digital Visiting Card

A mobile-first static landing page for the Karnataka Battery / Exide battery shop.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

Example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy

This can be deployed directly to any static hosting provider. The QR code printed on the physical visiting card should point to the deployed URL.

## Before production

1. Confirm the exact shop addresses and Google Maps locations for all three branches.
2. Confirm which contact person/name belongs to each branch.
3. Replace the generic Google Maps search URLs with exact Place/Maps URLs.
4. Confirm WhatsApp numbers before printing the QR card.
